Project Notes

作品说明

本作品适合作为《现代教育技术》期末作业中的“国际中文教育资源制作”网页资源。

教学性

围绕 HSK 写作训练设计等级选择、题目任务、文本输入、评分维度、批改建议和后续训练任务。

技术性

使用 HTML、CSS、JavaScript 实现响应式界面、文本统计、规则评分、划线标注、报告生成、本地语料记录和 CSV 导出。

创新性

将写作批改工具和语料收集后台结合，既能服务学习者，也能为教师后续分析学习者写作问题提供材料。

部署方式

本项目为纯静态网页，可直接本地打开，也可上传到 GitHub Pages。若需要真实多人语料库，可扩展连接 Supabase、Firebase 或学校服务器。
